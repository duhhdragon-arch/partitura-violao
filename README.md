# Violão para partitura

Toque violão ou teclado (piano, órgão, strings, pad) perto do microfone, ou envie uma gravação, e a página escreve a cifra numa pauta: andamento, tom, compassos e acordes. Modo Melodia para notas tocadas uma de cada vez, com pauta dupla no teclado.

Site: https://duhhdragon-arch.github.io/partitura-violao/

Tudo roda no navegador (Web Audio), sem servidor.
