# Violão para partitura

Toque perto do microfone (ou envie uma gravação) e a página escreve a cifra numa pauta: andamento, tom, compassos e acordes. Modo Melodia para notas tocadas uma de cada vez.

Site: https://duhhdragon-arch.github.io/partitura-violao/

Tudo roda no navegador (Web Audio), sem servidor.
